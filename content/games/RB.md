## Overview
Rolling back was my final student project at university. It was created as part of my dissertation for my game design course at the University of East London. The main objective of this project was to test how dynamic music effects the emotional state of the player when playing games. The project was developed within unreal engine 5, and music within FL studio it was developed from September 2025 - May 2026. 

The game was designed to be a "rage" game (a game specifically designed to be hard to complete). the music accompanying it would change based on the state of the character, i.e. if not moving, very quite, if moving slowly starts to ramp up, if moving fast it becomes very chaotic. I did have a few problems during development, specifically the with how the dynamic system switches to the correct track. Within the final build of the game, when switching tracks it momentarily plays every track before only playing the correct one resulting in an unpleasant amount of noise.
